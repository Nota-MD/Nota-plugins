# Backlinks

Shows the links around the current Markdown document:

- incoming `[[wiki links]]` and relative Markdown links from other notes;
- outgoing links, including repeated mentions with their line numbers;
- unresolved targets that still do not match a file, title, or alias.

The extension scans ordinary Markdown files in the workspace. It does not write
to notes or keep a separate link database. Choose **Extensions -> Open
backlinks** and use the buttons to open a matching note.
